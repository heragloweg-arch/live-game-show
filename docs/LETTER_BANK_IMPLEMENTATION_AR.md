# تنفيذ بنك الحروف والخلط — قدها

## ما تغير

### بنك الإجابة

أصبحت الأسئلة المعتمدة تستخدم عقدًا موحدًا:

- `letter_pool`: حروف الإجابة مع مشتتات محدودة.
- `max_length`: عدد أشرطة الإجابة.
- `challenge_answers`: الإجابة الصحيحة وتطبيعها خادميًا.
- لا تُرسل `is_correct` أو قائمة الاختيارات إلى العميل في مسارات البنك الجديد.

العميل يختار الحروف بالترتيب، ويعرض أشرطة فارغة بعدد الأحرف. لا يمكنه اختيار حروف بعد بلوغ `maxLength`.

### Solo / 1v1 / Couple

- تستبعد أسئلة `speed` من هذه الأنماط.
- تسحب فقط التحديات التي تملك `letter_pool`.
- لا يتكرر `challenge_id` داخل المباراة.
- لا يتكرر `subtype` في جولتين متتاليتين.
- لا تعتمد الجولة على ترتيب فئات جامد؛ السحب مختلط من البنك.

### Room / Host

- يسمح بأسئلة `speed` مع باقي الأسئلة.
- لا يتكرر السؤال داخل الغرفة طوال سجل جولات الغرفة.
- لا يتكرر `subtype` في جولتين متتاليتين.
- السؤال يرسل مع `letterPool` و`maxLength` فقط.
- التحقق والإجابة يبقيان خادميين.

## Migrations

1. `20260928000041_question_bank_review_queue.sql`
   - يستورد المرشحين البنيويين بعلامة `version=41`.
2. `20260928000042_letter_bank_activation.sql`
   - يحول المرشحين إلى بنك حروف.
   - ينشئ الإجابات الخادمية.
   - يوحد المحتوى القديم المعتمد الذي كان يعتمد على choices.
   - ينشئ فهرس اختيار بنك الحروف.
3. `20260928000043_content_approval_gate.sql`
   - ينشئ سجل اعتماد قابلًا للتتبع لكل سؤال.
   - لا يفعّل أي صف تلقائيًا.
   - يتطلب مراجعة وقائعية وصياغية، ومراجعة دينية مستقلة للفئات الدينية.
   - لا يمكن استدعاء دالة الاعتماد من العميل؛ صلاحيتها محصورة في `service_role`.

## ملاحظة جودة صادقة

Migration 042 لا تفعل أي سؤال؛ تجهيز `letter_pool` لا يعني اعتمادًا. Migration 043 لا تفعّل أي سؤال، بل تؤسس بوابة الاعتماد. التفعيل يحدث سؤالًا بسؤال عبر `approve_challenge_content` بعد المراجعة البشرية، مع منع اعتماد الدين/القرآن دون `religious_reviewed=true`. وتظل مراقبة البلاغات جزءًا من التشغيل؛ لا يمكن لقاعدة البيانات وحدها إثبات الصحة المعرفية لكل سؤال.

## تطبيق التشغيل

```bash
supabase db push
npx supabase functions deploy match
npx supabase functions deploy room
```

ثم يجب اختبار:

- اختيار الحروف حتى عدد الأشرطة.
- منع اختيار حرف إضافي.
- تطابق الإجابات العربية مع التطبيع الخادمي.
- عدم تكرار السؤال في مباراة أو غرفة.
- اختلاف الفئة بين جولتين متتاليتين.
- ظهور Speed في Host وعدم ظهوره في Solo/1v1/Couple.
