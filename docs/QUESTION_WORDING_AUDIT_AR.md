# تدقيق صياغة بنك الأسئلة — قدها

## النطاق

تم تدقيق صياغة الأسئلة المؤهلة بنيويًا فقط وعددها 968 سؤالًا. التدقيق لغوي وتحريري؛ لا يدّعي التحقق من صحة المعلومات، ولا يغيّر الخيارات أو `correctIndex`.

## النتيجة

| المؤشر | العدد |
|---|---:|
| الأسئلة الكلية في الطابور | 1,119 |
| الأسئلة المؤهلة للتدقيق | 968 |
| صياغات محسنة | 524 |
| حالات حساسة احتاجت تثبيتًا يدويًا | 26 |
| الخيارات أو الإجابة الصحيحة التي تم تغييرها | 0 |

تم تثبيت 26 حالة يدويًا بصياغات محافظة على المعنى. في سؤال «ألان الله له الحديد» رُفض اقتراح آلي كان سيغير المعنى، وأُبقيت الصياغة الصحيحة.

## سياسة الاعتماد

الاستيراد والتجهيز لا يعنيان تفعيل السؤال. كل صف يبقى قبل Migration 043:

```text
active = false
qa_status = needs_review
```

ولا يظهر في أي مباراة حتى يرفعه مسؤول المحتوى صراحة عبر سجل الاعتماد. Migration 043 لا تفعّل الصفوف تلقائيًا؛ بل تنشئ بوابة اعتماد سؤالًا بسؤال، وتفرض مراجعة دينية مستقلة للفئات الدينية. التدقيق اللغوي لا يستبدل المراجعة المعرفية؛ بل يعالج الصياغة فقط.
