# Soft Launch Playbook — SA + EG

## الهدف
قياس الاحتفاظ والجودة قبل أي حملة كبيرة.

## الأسواق
السعودية · مصر (أساسي) · الإمارات اختيارياً لاحقاً

## أسبوع 1–2
- تثبيت APK مغلق أو مسار اختبار داخلي
- 50–200 مستخدم نوعي (صناع محتوى / أصدقاء / مجموعات تحديات)
- راقب: إكمال المباراة، أعطال، شكاوى أسئلة

## أسبوع 3–4
- تحسين الأسئلة الضعيفة
- Host Show مع 3–5 مضيفين تجريبيين
- تقرير Metrics أول لـ Data Room

## إشارات «جاهز لتوسيع»
- إكمال مباراة ≥ 70%
- D1 في اتجاه ≥ 25% (أو تحسن أسبوعي واضح)
- Crash-free مرتفع
- لا ثغرات اقتصاد حرجة
