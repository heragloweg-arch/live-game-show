# تنفيذ مراجعة Red Team — قدها

## الإصلاحات المنفذة

1. **منحة الاشتراك اليومية:** تم إصلاح منطق `ON CONFLICT` باستخدام `RETURNING id` بدل الاعتماد على `FOUND`. أصبحت المنحة idempotent تحت التسابق، ويطبق Plus/Host Pro مبلغ 50 عملة تجميلية يوميًا، دون أي تأثير على نقاط المباراة أو XP أو صحة الإجابة.
2. **Rewarded Ads:** تم تقوية `request_id` ليستخدم UUID عند توفره، مع استمرار الحد الخادمي والتسوية الذرية.
3. **الرصيد:** أصبح `walletStore.loadWallet()` يجلب المحفظة وledger معًا، بحيث تعتمد الشاشات على snapshot خادمي واحد بدل رصيد محلي منفصل.
4. **آخر المنافسين:** أضيف API typed يقرأ المشاركين الحقيقيين في آخر المباريات المكتملة، مع قسم آخر المنافسين داخل الملف الشخصي وزر إعادة حقيقية يعتمد على `rematch` الخادمي.
5. **Creator:** أضيفت مكافأة 100 عملة تجميلية عند اعتماد السؤال، مع منع اعتماد السؤال المنشور مرة ثانية وقيد ledger خاص بـ `creator_approval`.
6. **Interstitial:** تمت مراجعة مساره؛ لا يستدعى إلا بعد `phase === finished` وبعد تأخير 1200ms، والسياسة الخادمية/المحلية تمنع ظهوره أثناء الجولة وتحترم Plus والحدود اليومية.
7. **Match typing:** أزيلت استخدامات `as any` الأساسية من دورة MatchScreen في الخطأ، الاتصال، الإجابة، المكافآت، وإعادة الاتصال.

## تحقق المصدر

نجحت بوابات:

```bash
npm run typecheck
npm run lint
npm test -- --run
npm run build
node scripts/verify-production.mjs
```

النتيجة: 6 ملفات اختبار، 16 اختبارًا ناجحًا، Production lock ناجح مع فحص 71 أصل JavaScript.
