# دفعة قدها — نظام الإجابة الموحد وشجرة Solo

**التاريخ:** 3 نوفمبر 2026  
**الفرع:** `main`  
**النطاق:** توحيد إدخال الإجابة في Match/Solo وDaily والغرف، وتحسين عرض تقدم ورقة Solo.

## ما أُغلق

أضيف `UnifiedAnswerInput` ليعالج الاختيارات والحروف والنص المفتوح بعقد واحد. الاختيار يرسل تلقائيًا، وإجابة الحروف ترسل عند اكتمال عدد الخانات، والنص المفتوح يرسل عبر Enter دون زر إرسال مرئي. ظلت التلميحات والحروف الزائدة محلية في واجهة الحروف، بينما بقي التحقق والنقاط والعملة وفتح الأوراق على الخادم.

أضيفت تغذية راجعة موحدة: الأخضر والاحتفال والاهتزاز للنتيجة الصحيحة، والأحمر والاهتزاز للنتيجة الخاطئة. Solo ينتقل للجولة التالية بعد وصول نتيجة الخادم، وDaily ينتقل للمحطة التالية بعد النتيجة. الغرف لا تتجاوز تحكم المضيف ومرحلة reveal.

أضيف شريط تقدم 0/3 داخل ورقة Solo الحالية، ونقاط الأسئلة الثلاثة داخل أوراق شجرة Solo، ولقب «بطل تحديات قدها» عند إكمال ورقة Solo وفق نتيجة الخادم. لم تُضف قيمة كوين محلية مختلقة.

## البوابات المحلية

- `npm run typecheck`: ناجح.
- `npm run lint`: ناجح مع عدم وجود أخطاء.
- `npm test -- --run`: 8 ملفات، 21 اختبارًا ناجحًا.
- `npm run test:production-gates`: 50 اختبارًا ناجحًا.
- `npm run build`: ناجح؛ تحذير LiveKit chunk الكبير قائم كبند P1 معروف.
- `node scripts/verify-production.mjs`: ناجح.
- `node scripts/verify-launch-config.mjs`: ناجح/تخطي وضع التطوير حسب العقد.
- `node scripts/verify-content-release.mjs`: ناجح لـ968 صفًا مدققًا دون تفعيل جماعي.
- `npm run verify:e2e-log`: ناجح بوصفه فحص أمانة؛ 10/10 سيناريوهات ما زالت `BLOCKED_EXTERNAL`.

## حدود صريحة

لم يُعلن ترتيب الكوين؛ خدمة `get_public_profiles` الحالية ترتب بالفوز ثم XP ولا تكشف coins، لذلك يحتاج ترتيب الكوين RPC خادميًا جديدًا ومراجعة خصوصية قبل تنفيذه. كذلك لم يُعلن PASS حيًا لـRailway أو Supabase أو الجهاز الحقيقي من هذه الدفعة؛ يلزم نشر هذه الشيفرة على main ثم التحقق من `/ready` وE2E ميداني.

**قرار Soft Launch:** لا، مشروط بإغلاق P0 وE2E وAAB وInternal Testing وBilling/AdMob الحي وفق `docs/LAUNCH_STATUS.md`.
