# دوري الأبطال — توليد الشبكة (Bracket)

## متى تُولَّد؟
تلقائياً عند `join` إذا `entriesCount >= max_players`.

أو يدوياً: `action: generate_bracket` / زر «توليد الشبكة الآن».

## الخوارزمية
- Single elimination
- خلط اللاعبين عشوائياً
- إكمال العدد لأقرب قوة 2 بـ BYE
- إنشاء جولة 1 + خانات الجولات التالية
- الفوز بالـBYE يتقدم تلقائياً
- `report_result` يحدّث الترتيب ويدفع الفائز للجولة التالية
- عند انتهاء كل المواجهات: `status = completed`
