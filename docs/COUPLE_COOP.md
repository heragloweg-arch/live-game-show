# ثنائي Co-op — قدها

## السلوك
- ثنائية `active` مطلوبة
- `create_couple` ينشئ مباراة `mode=couple` لنفس الجولات
- الطرفان مشاركان بشريان (لا AI)
- الانتقال للجولة التالية ينتظر **إجابة الاثنين** أو انتهاء الوقت (نفس بوابة canAdvanceRound)
- `teamScore` = مجموع نقاط الشريكين
- عند الإنهاء: تحديث `shared_wins` / `shared_matches` على جدول couples

## العميل
من شاشة الثنائي → «ابدأ جولات Co-op معاً» → `/match/:id`
