# Economy Spec — MVP (معتمد للمرحلة A)

## العملة
- **Coins** فقط في MVP.
- Gems / VIP / Billing مؤجلة بعد قياس الاحتفاظ.

## مصادر الكسب
| المصدر | المبلغ | ملاحظات |
|--------|--------|---------|
| فوز مباراة | +50 coins | مرة واحدة لكل matchId |
| خسارة | +15 coins | مرة واحدة لكل matchId |
| تعادل | +25 coins | |
| مكافأة يومية | +25 coins | مرة / يوم تقويمي |

## XP
| النتيجة | XP |
|---------|-----|
| فوز | +50 |
| خسارة | +20 |
| تعادل | +30 |

المستوى: عند امتلاء `xp_to_next` يرتفع المستوى ويزداد العتبة ×1.25.

## قواعد صارمة
- لا شراء إجابات.
- لا Pay-to-Win.
- كل منحة Coins عبر `credit_coins` + `wallet_ledger` مع `reference_id`.
- تكرار finish للمباراة نفسها لا يضاعف المكافأة.

## إعلانات / IAP
- خارج نطاق MVP الحالي.
