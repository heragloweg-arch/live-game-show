# وحدة اقتصادية أولية — زتونة

## فرضيات Soft Launch
- لا IAP في الأسابيع الأولى
- الإعلانات **مغلقة** حتى يثبت D1 والاتمام
- القيمة الحالية = تعلم المنتج + محتوى + Host

## بعد ثبات الاحتفاظ
| المصدر | ملاحظة |
|--------|--------|
| Rewarded Ad (اختياري) | عملات تجميلية فقط — لا إجابات |
| Interstitial بعد المباراة | بحد أقصى يمنع تدمير الجلسة |
| لاحقاً: حزم تجميل / إطارات | ليست قوة لعب |

## معادلات متابعة
- ARPDAU = إيراد اليوم / DAU
- كلفة اكتساب (CPI) vs LTV تقديري على 30 يوماً
- لا توسع مدفوع إن كان LTV < CPI بوضوح

## مبدأ صارم
**لا Pay-to-Win.** أي منتج يبيع الإجابة أو الوقت الحاسم يُرفض.
